One line, one cat, one reversal: a single joke about cats, written by a small deterministic program. The setup trains the cat to come when called; the turn reveals the cat trained the owner instead — to come at a single stare.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (101 characters, one line). No network, no randomness, no files read outside this repository.
